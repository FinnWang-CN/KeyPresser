# KeyPresser

## 1. Overview

KeyPresser is an open-source Windows tool for automating keystrokes. It can send input to a selected window while that window is in the background.

Choose a target window, use the checkboxes to select which keyboard messages to send, and pick a key from the dropdown. Set the interval between keystrokes, then use **Start** and **Stop** to control playback.

- **Free edition:** Download the source code from this repository and build it yourself.
- **Professional edition:** [Download from the official website](https://keypresser.onepeak.cn/index-en.html#download).
